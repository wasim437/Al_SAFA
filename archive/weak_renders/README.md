# Weak renders — withdrawn from the submission

These are matplotlib drawings that imitate photography: an aerial view built from coloured rectangles, eye-level views built from trapezoids and circles.

They were withdrawn because the 3D Visualisations slot also holds photoreal renders of the same subjects, and placing the two side by side invites a comparison the drawings cannot win. Nothing here is deleted; if a drawing is wanted again it is intact.

Genuine technical drawings — sections, elevations, planting plan, circulation and masterplan diagrams, presentation boards — were not touched. Those do a job a photograph cannot.
